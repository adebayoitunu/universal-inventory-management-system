# universal-inventory-management-system
A Python-based inventory management system designed to help small and medium-sized enterprises (SMEs) efficiently track products, monitor stock levels, and manage inventory transactions. The project focuses on accessibility and simplicity for users without advanced technical knowledge.

---

## 🧰 Features

- Add, update, and delete product records  
- Track quantities in stock, quantities sold, and cost prices  
- Automatically calculate total sales value and profit margins  
- Search and filter inventory by product ID, category, or supplier  
- Save and update data in CSV format for easy portability  

---

## Technologies Used

- **Python**
- **Pandas** for data manipulation and analysis
- **CSV files** for data storage
- **Jupyter Notebook** for code execution and testing

---

## Dataset Structure

Each record contains the following fields:
- `Product ID`
- `Product Name`
- `Category`
- `Quantity Ordered`
- `Quantity in Stock`
- `Quantity Sold`
- `Cost Price`
- `Unit Price`
- `Supplier`
- `Date of Entry`
